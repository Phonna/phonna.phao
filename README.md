# Phonna Phao — Personal Portfolio

A responsive, modern dark-themed personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Preview locally
1. Extract the ZIP file.
2. Open the `phonna-portfolio` folder.
3. Double-click `index.html` or open it in a browser.

No build tools or dependencies are required. An internet connection is used only for Google Fonts.

## Personalize before publishing
Open `index.html` and update:
- `YOUR_EMAIL@example.com` with the professional email address you want to publish.
- `https://www.linkedin.com/in/YOUR-LINKEDIN/` with your LinkedIn profile URL.
- The CV link in the Contact section. Add your PDF CV to the project (for example, `assets/Phonna-Phao-CV.pdf`) and change the link to that filename.
- Review the role, experience, expertise, and project descriptions for accuracy and comfort before publishing.
- Optionally add a professional headshot in the hero section.

## Publish free
### GitHub Pages
1. Create a GitHub repository (for example, `phonna-portfolio`).
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. GitHub will provide your public website URL.

### Netlify
1. Sign in to Netlify.
2. Choose **Add new site → Deploy manually**.
3. Drag the extracted `phonna-portfolio` folder into the deployment area.

## Project files
- `index.html` — website content and sections
- `styles.css` — responsive layout and visual design
- `script.js` — mobile navigation and small interactions
- `assets/` — add your CV, profile photo, or other portfolio assets here

## Privacy note
The sample project descriptions are generalized and intentionally avoid naming hotel clients or publishing system configuration details. Keep client information, credentials, screenshots, and internal support records out of the public portfolio.
